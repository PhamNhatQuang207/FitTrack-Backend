# FitTrack i18n (EN / VI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full English (`en`, default) and Vietnamese (`vi`) internationalization across FitTrack's Express/MongoDB backend, MCP tools, Admin UI, AI Coach, and React 19 frontend without breaking existing database schemas or URLs.

**Architecture:** The backend remains canonical in English while adding `preferredLanguage` on `users`, `translations.vi` on `exercises` and `muscle_groups` (with default Vietnamese seeding for the 14 built-in muscle groups), `Accept-Language` middleware, standardized API `code` errors, bilingual styled HTML + plain-text email templates, and language-aware AI prompts + MCP search. The frontend uses `i18next` + `react-i18next` with `localStorage` persistence, sends `Accept-Language` via Axios, syncs `preferredLanguage` through `buildUser` / `AuthContext`, and resolves both catalog items and embedded workout/schedule snapshots with automatic fallback to English.

**Tech Stack:** Node.js, Express 5, MongoDB 7, Jest + Supertest (`server/`); React 19, `i18next`, `react-i18next`, `i18next-browser-languagedetector`, Axios, React Testing Library (`client/`).

**Spec:** `server/docs/superpowers/specs/2026-11-16-i18n-en-vi-design.md`

## Global Constraints

- Supported locales: `'en'` (default and fallback) and `'vi'` only (`load: 'languageOnly'`).
- URLs remain unchanged (`/workouts`, `/dashboard`, etc.); no locale path prefixes.
- Weight units remain fixed to `kg` (translate labels only, no `kg` ↔ `lbs` conversion).
- Catalog schema is non-breaking: root `name`, `category`, `instructions` stay in English; Vietnamese overrides live under optional `translations.vi`.
- Missing or empty `translations.vi` fields must automatically fall back to the English root field.
- Embedded workout/plan/schedule snapshots (`{ exerciseId, exerciseName, category }`) must resolve localized display names via cached `exercises` and `muscle_groups` catalogs.
- AI Coach must continue querying `search_fitness_knowledge` in English even when responding in Vietnamese.

```javascript
// server/src/middleware/localeMiddleware.js
function localeMiddleware(req, _res, next) {
  const header = String(req.headers['accept-language'] || '').trim().toLowerCase();
  req.lang = header.startsWith('vi') ? 'vi' : 'en';
  next();
}

module.exports = localeMiddleware;
```

```javascript
const ALLOWED_LANGUAGES = ['en', 'vi'];

const updateLanguage = async (req, res) => {
    try {
        const { preferredLanguage } = req.body || {};
        if (!ALLOWED_LANGUAGES.includes(preferredLanguage)) {
            return res.status(400).json({
                code: 'USER_INVALID_LANGUAGE',
                message: 'preferredLanguage must be "en" or "vi"',
            });
        }
        const db = getDb();
        const result = await db.collection('users').updateOne(
            { _id: new ObjectId(req.userId) },
            { $set: { preferredLanguage, updatedAt: new Date() } }
        );
        if (result.matchedCount === 0) {
            return res.status(404).json({ code: 'USER_NOT_FOUND', message: 'User not found' });
        }
        res.json({ preferredLanguage });
    } catch (error) {
        res.status(500).json({ code: 'INTERNAL_ERROR', message: error.message });
    }
};
```

```javascript
// client/src/utils/localize.js
export function getLocalizedField(item, field, lang = 'en') {
  if (!item) return '';
  const normalizedLang = String(lang || 'en').startsWith('vi') ? 'vi' : 'en';
  if (normalizedLang === 'en') return item[field] ?? '';
  const translated = item.translations?.[normalizedLang]?.[field];
  if (Array.isArray(translated)) {
    return translated.length > 0 ? translated : (item[field] ?? []);
  }
  return translated && String(translated).trim() !== '' ? translated : (item[field] ?? '');
}

export function getLocalizedExerciseName(exerciseOrSnapshot, exercisesCatalog = [], lang = 'en') {
  if (!exerciseOrSnapshot) return '';
  if (exerciseOrSnapshot.translations) {
    return getLocalizedField(exerciseOrSnapshot, 'name', lang) || exerciseOrSnapshot.exerciseName || '';
  }
  const targetId = exerciseOrSnapshot.exerciseId || exerciseOrSnapshot.id;
  const targetName = exerciseOrSnapshot.exerciseName || exerciseOrSnapshot.name || '';
  const match = Array.isArray(exercisesCatalog)
    ? exercisesCatalog.find(
        (ex) =>
          (targetId && String(ex.id || ex._id) === String(targetId)) ||
          (targetName && ex.name?.toLowerCase() === targetName.toLowerCase())
      )
    : null;
  if (match) {
    return getLocalizedField(match, 'name', lang);
  }
  return targetName;
}

export function getLocalizedMuscleGroupName(categoryName, muscleGroupsCatalog = [], lang = 'en') {
  if (!categoryName) return '';
  const normalizedLang = String(lang || 'en').startsWith('vi') ? 'vi' : 'en';
  if (normalizedLang === 'en') return categoryName;
  const match = Array.isArray(muscleGroupsCatalog)
    ? muscleGroupsCatalog.find((g) => g.name?.toLowerCase() === String(categoryName).toLowerCase())
    : null;
  return match ? getLocalizedField(match, 'name', normalizedLang) : categoryName;
}

export function getApiErrorMessage(error, t, fallbackMessage = '') {
  const code = error?.response?.data?.code;
  const serverMsg = error?.response?.data?.message || error?.message || fallbackMessage;
  if (code && typeof t === 'function') {
    const translated = t(`errors:${code}`, { defaultValue: serverMsg || code });
    if (translated && translated !== `errors:${code}`) return translated;
  }
  return serverMsg;
}
```

```javascript
const LOCALE_MAP = { en: 'en-US', vi: 'vi-VN' };

export function formatDate(date, lang = 'en', options = { dateStyle: 'medium' }) {
  if (!date) return '';
  const key = String(lang || 'en').startsWith('vi') ? 'vi' : 'en';
  return new Intl.DateTimeFormat(LOCALE_MAP[key], options).format(new Date(date));
}

export function formatNumber(value, lang = 'en', options) {
  if (value === null || value === undefined || Number.isNaN(Number(value))) return '';
  const key = String(lang || 'en').startsWith('vi') ? 'vi' : 'en';
  return new Intl.NumberFormat(LOCALE_MAP[key], options).format(Number(value));
}
```
